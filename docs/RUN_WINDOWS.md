# Запуск на Windows

Все команды вводятся в PowerShell, открытом в папке проекта. Чтобы его открыть: Проводник → папка проекта →
клик по адресной строке → набрать `powershell` → Enter.
Если команда `py` не находится, пишите `python` вместо `py`.

## Один раз: перенести ключи из папки проекта

Папку проекта придётся заменять при каждом обновлении (новый ZIP с GitHub). Чтобы ключи не потерялись,
храните `.env` рядом с `wallet.key`. Бот сам ищет его в `C:\Users\<имя>\.updown-bot\.env`.

В PowerShell в **старой** папке проекта (где сейчас лежит `.env`):
```
Move-Item .env "$HOME\.updown-bot\.env"
```

## Один раз (с версии M2): перенести записанные данные

Теперь данные по умолчанию пишутся в `C:\Users\<имя>\.updown-bot\data`, а не в папку проекта, чтобы не пропадать
при обновлении. Данные, записанные раньше, перенесите командой в PowerShell в **старой** папке проекта (где лежит
папка `data`):
```
Move-Item data "$HOME\.updown-bot\data"
```

## Обновить проект до новой версии

1. Скачать ZIP ветки: https://github.com/illnessbolen/updown-twap-bot/tree/claude/intelligent-dirac-9z1dv1 →
   **Code** → **Download ZIP**.
2. Удалить старую папку `C:\updown-twap-bot` (ключи и данные уже лежат в `.updown-bot`) и распаковать новую на её место.
   Внутри должны быть `CLAUDE.md`, папки `updown`, `docs`, `scripts`, `tests`.
3. Если вы меняли `config.toml`, перед удалением сохраните его копию.

## Первый запуск после обновления

```
py -m pip install "websockets>=15,<16"
copy config.example.toml config.toml
py -m updown check
```

`check` должен показать:
- `Конфиг: config.toml - OK ...`
- `.env: C:\Users\...\.updown-bot\.env`
- `Ключи PolyBolt: есть (apiKey ...)`
- `Режим: DRY_RUN, реальных ордеров нет ...`
- `Часы: расхождение с сервером ...`. Если больше 2 с, включите синхронизацию: Параметры → Время и язык →
  Дата и время → «Синхронизировать».

## Текущие рынки

```
py -m updown markets
```
Показывает текущие и ближайшие рынки BTC/ETH 5m и 15m: время, шаг цены, комиссию, токены Up/Down.

## Запись данных

```
py -m updown record
```

Каждые 30 секунд печатаются строки:
- `цены | btcusd TWAP ... | свежие: {...}` - цены PolyBolt;
- `рынок btc-updown-5m-... | осталось ... с | strike ... | Up bid/ask ... | стакан свежий` - по каждому идущему рынку;
- `стаканы | токенов ... | расхождений ... | переподключений ...` - стаканы CLOB.

Данные пишутся в `C:\Users\<имя>\.updown-bot\data\ГГГГ-ММ-ДД\` (дата по UTC), сжатыми (`.jsonl.gz`). Каждый запуск пишет свои файлы,
старые не трогает. Остановка: Ctrl+C.

Сводка за сегодня (UTC):
```
py -m updown feed-stats
```
За другой день: `py -m updown feed-stats --day 2026-10-03`.

## Проверка strike

Через несколько минут после конца окна Polymarket публикует свой strike и итог. Сравнить с тем, что посчитал бот:
```
py -m updown strike-check
py -m updown strike-check --day 2026-10-03 --day 2026-10-04
```
Строки «strike = принт ровно на начале окна» и «исход Up/Down совпал» должны показывать все рынки (например 120/120).

Для записи на несколько дней отключите сон компьютера: Параметры → Система → Питание → «Переводить в режим
сна» → Никогда. Иначе запись остановится, когда компьютер уснёт.

## Если что-то не так

| Сообщение | Что значит |
|---|---|
| `Ошибка конфигурации: нет POLY_API_KEY ...` | бот не нашёл `.env`; проверьте `C:\Users\<имя>\.updown-bot\.env` |
| `остановка: ... 4001` или `auth_invalid` | PolyBolt не принял ключи; получите их заново (`scripts/get_clob_api_key.py --key-file ... --force`) |
| `reconnect_wait ... HTTP 403` | доступ запрещён: гео-ограничение, VPN или фаервол |
| `stale ... нет данных` | данные перестали приходить; бот переподключается сам, это нормально, если редко |
| `book reconnect_wait ... код 1013` | сервер стаканов попросил переподключиться (бывает у смены окна); бот делает это сам |
| `Ошибка конфигурации: нет секций ...` | после обновления скопируйте заново `config.example.toml` в `config.toml` |

Ключи и содержимое `.env` никому не отправляйте и на GitHub не загружайте.
